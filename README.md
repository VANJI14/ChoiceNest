# ChoiceNest Frontend

Frontend-only version of ChoiceNest using HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive homepage
- Product listing and search
- Category filtering
- Wishlist
- Signup / Login / Logout demo
- User profile
- Recently viewed tracking
- Affiliate click tracking
- Browser localStorage

## Important
This is a frontend demo. Passwords and account data are stored in localStorage only and are NOT secure for a real production website.

For the final version, connect the frontend to your Spring Boot API and MySQL/Supabase backend.
